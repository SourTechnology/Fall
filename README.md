# Fall!
Fall! is a file-sharing app concept where two people use Fall codes to join a shared room.
Run locally

Save the project code as index.html.
Open it in a modern browser.
Share your displayed code with a friend, then enter their code to open the room.

# Current status
This single-file prototype generates codes and previews selected files locally. It does not connect devices or transfer files. Real sharing requires a backend for room coordination and a secure transfer method, such as WebRTC with a signaling server.
# Security
Don’t use this prototype to share sensitive files. Before launching a real service, add secure, expiring room codes, access controls, and protections against unauthorized access.
